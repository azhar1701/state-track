## 🔍 Cara Mencari Dokumentasi

1. **Berdasarkan Topik:**
   - Fitur → `features/`
   - Teknis → `technical/`
   - Panduan → `guides/`
   - Referensi → `reference/`

2. **Berdasarkan Peran:**
   - Developer → `guides/` + `technical/`
   - Admin → `reference/ADMIN_*`
   - Peneliti → `academic/`

3. **Berdasarkan Kebutuhan:**
   - Setup awal → `guides/SETUP_GUIDE.md`
   - Troubleshooting → `guides/` + `reference/`
   - Optimasi → `technical/PERFORMANCE_OPTIMIZATION.md`

## 📝 Konvensi Penamaan

- `KTI_*` - Karya Tulis Ilmiah (Academic Paper)
- `*_GUIDE.md` - Panduan langkah-demi-langkah
- `*_QUICKSTART.md` - Quick start guide
- `*_REFERENCE.md` - Referensi teknis
- `*_SUMMARY.md` - Ringkasan/overview

## 🤝 Kontribusi

Untuk menambah atau memperbarui dokumentasi:

1. Tempatkan file di folder yang sesuai
2. Update README.md ini jika menambah kategori baru
3. Gunakan format Markdown yang konsisten
4. Tambahkan link di Quick Links jika relevan
